# Ledger Bank Frontend

Static frontend for the Ledger Bank demonstration.

## Main product areas

- `index.html` — public product website
- `auth.html` — authentication
- `dashboard.html` — authenticated overview
- `transactions.html` — Payments workspace
- `manage.html` — account management

Supporting product pages:

- `features.html`
- `security.html`
- `help.html`
- `about.html`

The frontend talks to the existing API at `http://localhost:4000/api` through `js/api.js`.
